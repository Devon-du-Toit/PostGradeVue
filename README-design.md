# Sage Studio

Inspired by the soft green dashboard palette, botanical layouts, and light login references in the shared UI Inspiration folder.

This proposal uses a full desktop navigation sidebar and a course-first dashboard. A right-hand overview rail holds the live metrics, verification action, and workflow. The sign-in form sits in a contained two-panel composition.

The calm sage canvas, white surfaces, rounded forms, and restrained green action color continue through the lecturer workspace. The existing theme toggle remains available; first-time visitors start in the light variant.
