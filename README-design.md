# Midnight Signal

Inspired by the navy and electric blue analytics dashboards and high-contrast login references in the shared UI Inspiration folder.

This proposal uses a two-row horizontal command bar, an analytics dashboard with top-row metrics and a full-width course table, and a sign-in split with the message on the left and the form on the right.

The data-console palette, crisp borders, restrained chart motif, and cool blue actions carry through navigation, forms, tables, and cards. The existing light-mode toggle remains available.
